## ShowCoords - Mod for Minecraft Java Edition 26.3 (Fabric)

This is a really simple Mod to show your current coordinates and the biome you are in in the top left of your screen. Really subtle, really simple

The NeoForge 1.21.1 version lives on the `master` branch.

## Requirements

- Minecraft 26.3
- [Fabric Loader](https://fabricmc.net/use/) 0.19.5 or newer
- [Fabric API](https://modrinth.com/mod/fabric-api)
- Java 25

## Installation information

### Download prebuilt version

Just head to the releases tab and download the .jar file. Put that into your Minecraft mods folder and you are done

### Build it yourself

Use a JDK 25 (e.g. Microsoft Build of OpenJDK or Eclipse Temurin 25). Then build with `./gradlew build` and drag `build/libs/showcoords-fabric-1.0.0.jar` into your Minecraft mods folder
